One deadpan TV weather forecast for a city that does not exist, written to
`/output/entry.txt` by `main.ts`.

> Good evening from Drizzlewick, where fog has cut visibility to 3 feet, so today's sunrise is postponed until further notice, weather permitting.

Run it with `node main.ts`. The program self-checks the gate first: one line,
1 to 160 characters, not only whitespace.

See the competition on [make.fun](https://make.fun/bounty/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c).
